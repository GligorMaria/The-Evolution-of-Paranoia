From Thriller to Pandemic: A Data Mining Comparison of MJ and Covid-19 Conspiracies.
How does a conspiracy theory grow, mutate, and capture the public imagination? This project uses Natural Language Processing (NLP) to conduct a comparative data mining analysis across two eras of misinformation: the pop-culture shock of Michael Jackson’s death in 2009 and the global anxiety of the Covid-19 pandemic in 2020. By applying Text Preprocessing, Topic Modeling, Named Entity Recognition (NER), and Sentiment Analysis, we map how rumors evolve from localized internet forums to global social media feeds. Ultimately, we reveal the underlying linguistic patterns, shifting emotional cycles, and core structural similarities that define modern conspiracy theories.
